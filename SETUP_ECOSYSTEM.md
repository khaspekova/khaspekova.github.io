# Как настроить ecosystem.config.js

Этот файл нужен для запуска вашего Next.js приложения через PM2 на сервере Beget.

## ⚠️ Важно: Docker контейнер на Beget

**Beget использует Docker контейнеры для Node.js.** Это значит:

- Все команды Node.js/npm/PM2 выполняются **внутри Docker контейнера**
- Сначала подключаетесь к серверу: `ssh username@server`
- Потом входите в Docker: `ssh localhost -p 222`
- Внутри Docker вы увидите: `(docker) username@server: [0]~`

## Шаг 1: Найдите путь к вашему проекту на сервере

### Способ 1: Через Docker контейнер (правильный способ)

1. Подключитесь к серверу через SSH:

   ```bash
   ssh username@your-server.beget.com
   ```

2. **Войдите в Docker контейнер** (как в инструкции Beget):

   ```bash
   ssh localhost -p 222
   # Введите пароль
   # Вы должны увидеть: (docker) username@server: [0]~
   ```

3. Перейдите в директорию вашего проекта (куда вы загрузили файлы):

   ```bash
   cd /path/to/your/project
   ```

4. Узнайте текущий путь **внутри Docker**:

   ```bash
   pwd
   ```

   Вы увидите что-то вроде:

   - `/home/username/www/yourdomain.com`
   - `/home/username/public_html`
   - `/var/www/yourdomain.com`

5. **Скопируйте этот путь** — он нужен для `cwd` в конфиге

**Важно**: Путь внутри Docker может отличаться от пути на обычном SSH. Всегда проверяйте путь внутри Docker!

### Способ 2: Через File Manager в панели Beget

1. Откройте File Manager в панели управления Beget
2. Перейдите в директорию вашего проекта
3. Обычно путь отображается вверху или в адресной строке
4. Полный путь обычно начинается с `/home/username/...`

### Способ 3: Через команду find (если знаете имя файла)

```bash
# На сервере через SSH
find ~ -name "package.json" -type f 2>/dev/null | head -1
```

Это покажет путь к вашему проекту.

## Шаг 2: Узнайте правильный порт

### Способ 1: Спросите у поддержки Beget

Напишите в поддержку:

- "Какой порт нужно использовать для Node.js приложения?"
- "На каком порту должен работать мой Next.js сервер?"

### Способ 2: Проверьте настройки хостинга

В панели Beget найдите:

- Раздел "Node.js Applications" или "Applications"
- Там может быть указан порт
- Или информация о том, какой порт использовать

### Способ 3: Проверьте переменные окружения

Если на сервере есть файл `.env` или настройки окружения:

```bash
# На сервере
cat .env | grep PORT
# или
env | grep PORT
```

### Обычные порты на Beget:

- `3000` — стандартный порт для Node.js
- `3001`, `3002` и т.д. — если 3000 занят
- Или специальный порт, назначенный Beget

**Если не уверены — используйте 3000, но лучше уточнить у поддержки.**

## Шаг 3: Обновите ecosystem.config.js

Откройте файл `ecosystem.config.js` и замените:

1. **`cwd`** (строка 28):

   ```javascript
   cwd: "/home/yourusername/www/yourdomain.com", // Ваш реальный путь
   ```

2. **`PORT`** (строка 35):
   ```javascript
   PORT: 3000, // Или другой порт, который вам назначили
   ```

### Пример готового файла:

```javascript
module.exports = {
  apps: [
    {
      name: "kukuruku02",
      script: "node_modules/next/dist/bin/next",
      args: "start",
      cwd: "/home/myuser/www/mysite.com", // ✅ Обновлено
      instances: 1,
      exec_mode: "fork",
      env: {
        NODE_ENV: "production",
        PORT: 3000, // ✅ Обновлено (или другой порт)
      },
      error_file: "./logs/err.log",
      out_file: "./logs/out.log",
      log_date_format: "YYYY-MM-DD HH:mm:ss Z",
    },
  ],
};
```

## Шаг 4: Загрузите файл на сервер

Загрузите обновленный `ecosystem.config.js` в корень вашего проекта на сервере (туда же, где `package.json`).

## Шаг 5: Запустите приложение

**Важно**: Все команды выполняются **внутри Docker контейнера**!

```bash
# 1. Подключитесь к серверу
ssh username@your-server.beget.com

# 2. Войдите в Docker контейнер
ssh localhost -p 222
# Вы должны увидеть: (docker) username@server: [0]~

# 3. Перейдите в директорию проекта
cd /path/to/your/project

# 4. Запустите PM2 с этим конфигом
pm2 start ecosystem.config.js

# 5. Проверьте статус
pm2 status

# 6. Сохраните конфигурацию
pm2 save

# 7. Посмотрите логи (если нужно)
pm2 logs kukuruku02
```

**Выход из Docker**: Наберите `exit` чтобы вернуться в обычный SSH.

## Проверка

**Внутри Docker контейнера**:

```bash
# Убедитесь, что вы в Docker (видите (docker) в промпте)
# Проверьте статус
pm2 status
```

Вы должны увидеть ваше приложение в списке со статусом "online".

Если есть ошибки:

```bash
pm2 logs kukuruku02
```

Это покажет логи и поможет найти проблему.

## Работа с Docker контейнером

**Подключение к Docker:**

```bash
ssh username@server          # Сначала на сервер
ssh localhost -p 222          # Потом в Docker
```

**Выход из Docker:**

```bash
exit                         # Вернётесь в обычный SSH
exit                         # Ещё раз - отключитесь от сервера
```

**Если Docker перезапустился:**

- PM2 может не запуститься автоматически
- Подключитесь к Docker: `ssh localhost -p 222`
- Запустите PM2: `pm2 start ecosystem.config.js`

## Частые проблемы

### "Error: Cannot find module"

- Проверьте путь в `cwd` — он должен указывать на корень проекта
- Убедитесь, что в этой директории есть `node_modules` и `package.json`

### "Port already in use"

- Порт занят другим приложением
- Измените `PORT` на другой (например, 3001)
- Или остановите другое приложение: `pm2 stop <app-name>`

### "Permission denied"

- Проверьте права доступа к директории проекта
- Убедитесь, что вы находитесь в правильной директории
