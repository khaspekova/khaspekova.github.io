# Как узнать правильный порт для Next.js на Beget

## Проблема

Вы получили ошибку: `EPERM: operation not permitted :::3000`

Это означает, что порт 3000 недоступен. Нужно найти правильный порт.

## Способы найти правильный порт

### Способ 1: Спросить у поддержки Beget (Самый надёжный)

**Что делать:**

1. Напишите в поддержку Beget
2. Скажите им:
   - "Получаю ошибку EPERM на порту 3000 для Node.js приложения"
   - "Какой порт нужно использовать для моего Node.js/Next.js приложения?"
   - "Какой порт назначен для моей учётной записи?"

**Они скажут вам точный порт** - это самый надёжный способ.

### Способ 2: Проверить в панели управления Beget

1. Войдите в панель управления Beget
2. Найдите разделы:
   - **"Node.js Applications"** или **"Applications"**
   - **"Hosting Settings"** → **"Node.js"**
   - **"VPS Management"** (если у вас VPS)
3. Там может быть указан порт для Node.js приложений

### Способ 3: Попробовать разные порты (Метод проб и ошибок)

Попробуйте порты по порядку, пока не найдёте рабочий:

```bash
# Внутри Docker контейнера
ssh localhost -p 222

# Остановите текущий процесс
pm2 stop kukuruku02
pm2 delete kukuruku02

# Попробуйте порт 3001
pm2 start node_modules/next/dist/bin/next --name kukuruku02 -- start --port 3001
pm2 logs kukuruku02
# Если видите ошибку EPERM - порт не подходит

# Если 3001 не работает, попробуйте 3002
pm2 stop kukuruku02
pm2 delete kukuruku02
pm2 start node_modules/next/dist/bin/next --name kukuruku02 -- start --port 3002
pm2 logs kukuruku02

# И так далее: 3003, 3004, 3005...
```

**Признаки успеха:**

- В логах НЕТ ошибки EPERM
- Видите сообщение типа "Ready on http://localhost:3001"
- `pm2 status` показывает статус "online" без постоянных перезапусков

### Способ 4: Проверить переменные окружения

```bash
# Внутри Docker контейнера
cd /path/to/your/project

# Проверьте .env файлы
cat .env | grep PORT
cat .env.production | grep PORT

# Проверьте системные переменные
env | grep PORT
```

### Способ 5: Проверить документацию Beget

1. Найдите документацию Beget по Node.js
2. Там может быть указан стандартный порт
3. Или инструкции, как узнать свой порт

### Способ 6: Использовать IPv4 вместо IPv6

Иногда проблема в IPv6. Попробуйте принудительно использовать IPv4:

```bash
# Остановите процесс
pm2 stop kukuruku02
pm2 delete kukuruku02

# Запустите с IPv4 и портом 3001
HOSTNAME=127.0.0.1 pm2 start node_modules/next/dist/bin/next --name kukuruku02 -- start --port 3001

# Проверьте логи
pm2 logs kukuruku02
```

### Способ 7: Проверить, какие порты уже используются

```bash
# Внутри Docker контейнера
netstat -tuln | grep LISTEN
# или
ss -tuln | grep LISTEN
```

Это покажет, какие порты заняты. Избегайте их.

## Рекомендуемый порядок действий

1. **Сначала**: Напишите в поддержку Beget (Способ 1) - самый быстрый и надёжный
2. **Пока ждёте ответа**: Попробуйте порты 3001, 3002, 3003 (Способ 3)
3. **Если нашли рабочий порт**: Запишите его и используйте везде

## После того как узнали порт

### 1. Запустите Next.js с правильным портом:

```bash
pm2 start node_modules/next/dist/bin/next --name kukuruku02 -- start --port 3001
# (замените 3001 на ваш порт)
```

### 2. Обновите ecosystem.config.js (если используете):

```javascript
env: {
  NODE_ENV: "production",
  PORT: 3001, // Ваш порт
}
```

### 3. При настройке reverse proxy укажите правильный порт:

Скажите поддержке Beget:

- "Мой Next.js работает на `http://localhost:3001`" (ваш порт)
- "Настройте reverse proxy с моего домена на `http://localhost:3001`"

## Частые порты на Beget

- `3000` - стандартный, но часто недоступен
- `3001`, `3002`, `3003` - часто работают
- `8080`, `8081` - иногда используются
- Или специальный порт, назначенный Beget (например, `12345`)

## Что делать, если ничего не работает?

1. Убедитесь, что вы внутри Docker контейнера: `ssh localhost -p 222`
2. Проверьте, что Node.js установлен: `node --version`
3. Проверьте права доступа
4. Напишите в поддержку Beget с описанием проблемы

## Пример сообщения в поддержку

```
Здравствуйте!

Разворачиваю Next.js приложение на вашем хостинге.
При запуске получаю ошибку: "EPERM: operation not permitted :::3000"

Подскажите, пожалуйста:
1. Какой порт нужно использовать для Node.js приложения на моём тарифе?
2. Нужно ли как-то специально настраивать порт?
3. Какой порт назначен для моей учётной записи?

Спасибо!
```
